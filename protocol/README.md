# Protocol

- `protocol_v1.1_pt.md`: the review protocol, version 1.1, dated September 27, 2026, in its original language (Portuguese). It defines the objective, research questions, PICOC scope, sources, search strings, eligibility criteria, selection process, extraction fields, quality criteria, synthesis plan and canonical readings for RQ7. Section 15.3 of this file lists the amendments.
- `amendments/amendments.csv`: one row per amendment (A1–A27), with the date, the protocol sections affected, the change and the rationale, summarized in English.
- `amendments/amendments_original_pt.md`: the amendments table exactly as recorded in the protocol.

The protocol was written before the search but was not preregistered (amendment A2). There is no frozen copy from before the search other than v1.1, and every later change was recorded as a dated amendment. No amendment should be read as preregistered.

In this repository copy of the protocol, three fields that had been left blank were filled with factual values: the second reviewer's name (identity not disclosed) and the OSF registration DOI and date (not registered, amendment A2). The operational checklist at the end of the protocol (*Anexo: roteiro operacional*) is the task list written before the search and was not updated as tasks were done; the amendments record what was actually done.
