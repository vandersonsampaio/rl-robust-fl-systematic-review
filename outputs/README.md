# Outputs

- `generated_tables_and_figures/paper_tables/` and `paper_figures/` hold the LaTeX tables and TikZ/pgfplots figures as included in the paper.
- `generated_tables_and_figures/from_repository/` holds the tables (CSV and Markdown) and figures (CSV and SVG) regenerated from the data in this repository by `scripts/tables.py` and `scripts/figures.py`.
- `generated_tables_and_figures/synthesis_summary_pt.md` is the synthesis report produced by `scripts/pipeline/sintese.py` (in Portuguese), with the per-study RQ2 table and the quality map.
